# Ranjit-Sorting-Widget-2.0
Ranjit Sorting Scanner is a Chrome extension for Pathao Hermes that automates parcel sorting. Scan a Consignment ID and it instantly finds the matching row and clicks "Sticker Print &amp; At Sorting". QR Scan Mode extracts the CID from codes like 3000,CID,CR1. Features a draggable, resizable widget that remembers its position. Runs fully offline.
